# Agente de desenvolvimento para Devin CLI

O fluxo pronto para uso está em [AGENTS.md](AGENTS.md). O Devin CLI carrega esse arquivo automaticamente quando ele está na raiz do projeto. Copie-o para o repositório em que o agente trabalhará ou use seu conteúdo como instrução ao iniciar uma sessão.

Execute o fluxo com o **agente principal interativo** do Devin CLI. O processo exige perguntas e aprovações do usuário; perfis de subagentes personalizados não recebem a ferramenta de perguntas ao usuário.

Os links e comandos de instalação das quatro skills estão concentrados na tabela **Catálogo de skills** do `AGENTS.md`, para facilitar substituições. O arquivo [plan.md](plan.md) preserva a solicitação original.

Referências: [regras e AGENTS.md](https://docs.devin.ai/cli/extensibility/rules) e [limites dos subagentes](https://docs.devin.ai/cli/subagents).
